# qg-scratch-editeur

Éditeur Scratch (scratch-gui, AGPL-3.0) intégré au « QG des missions » (initiation Scratch 4e), publié sur GitHub Pages et chargé dans une iframe du QG.

Pour l'instant : `index.html` = page de diagnostic réseau à ouvrir sur un Chromebook élève (github.io, bibliothèque de lutins Scratch, jsDelivr, IndexedDB, taille d'écran).
